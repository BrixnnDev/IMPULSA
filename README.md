# IMPULSA — StockFlow

Sistema de gestión de inventario, punto de venta (POS) y digitación de productos.

Construido con **React + Vite**, **Tailwind CSS 4**, **React Router** y **React Icons**. Tema oscuro con acentos azules.

## Características

- Landing page profesional con hero, planes y precios, casos de éxito, estadísticas y más
- Autenticación: registro, inicio de sesión y recuperación de contraseña (localStorage)
- Selección de perfil con dos dashboards:
  - **POS**: panel de ventas, inventario con ajuste de stock y caja para vender
  - **Digitación**: registro de productos, movimientos (entradas/salidas/ajustes) y validación

## Ejecución

```bash
npm install
npm run dev      # desarrollo
npm run build    # producción
npm run lint     # oxlint
```

Con Bun:

```bash
bun install
bun run dev
```
